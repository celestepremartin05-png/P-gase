# Pégase

Logiciel de gestion du Domaine Apolo : accueil, calendrier, offres, prospects, clients et élèves, argent & stats, chevaux, personnel, réglages.

L'application est publiée comme artifact Claude : https://claude.ai/artifact/BS7wkqX4uJGspSxyWLsNGq

`index.html` est une copie du code publié. Les données (prospects, agenda, chevaux…) sont stockées dans la base de l'artifact, pas dans ce dépôt.
